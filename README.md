# Documentação de Sistemas

Este repositório contém projetos Java com exemplos de documentação utilizando JavaDoc.

## Estrutura do Projeto

- **[IntroduzindoJavaDoc](./IntroduzindoJavaDoc)**: Introdução ao uso de JavaDoc para documentação de código Java.
- **[os-tres-porquinhos](./os-tres-porquinhos)**: Projeto temático baseado na história "Os Três Porquinhos" demonstrando documentação JavaDoc.
- **[adivinhe-o-numero](./adivinhe-o-numero)**: Jogo "Adivinhe o Número" em Java com documentação JavaDoc (novo diretório adicionado).

## Tecnologias Utilizadas

- Java
- JavaDoc

## Como contribuir

1. Faça um fork do repositório.
2. Crie uma branch com sua feature: git checkout -b minha-feature
3. Faça commits das suas alterações: git commit -am 'Minha contribuição'
4. Envie para o repositório remoto: git push origin minha-feature
5. Abra um Pull Request descrevendo suas mudanças.
