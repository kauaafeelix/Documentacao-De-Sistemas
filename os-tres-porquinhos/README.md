# Os Três Porquinhos

Projeto temático baseado na história clássica "Os Três Porquinhos", demonstrando o uso de JavaDoc para documentação.

## Descrição

Este projeto implementa conceitos da história dos três porquinhos utilizando programação orientada a objetos em Java, com documentação completa usando JavaDoc.

## Estrutura

```
os-tres-porquinhos/
├── src/
│   ├── Main.java
│   ├── animais/
│   │   ├── LoboMau.java
│   │   └── Porquinho.java
│   └── casa/
│       ├── Casa.java (interface)
│       ├── CasaDePalha.java
│       ├── CasaDeMadeira.java
│       └── CasaDeTijolo.java
└── templates/
    └── [documentação JavaDoc gerada]
```

## Classes

### Pacote `animais`
- **LoboMau**: Representa as ações do vilão da história.
- **Porquinho**: Representa os porquinhos da história.

### Pacote `casa`
- **Casa**: Interface que representa o conceito geral de uma casa.
- **CasaDePalha**: Implementação da casa de palha.
- **CasaDeMadeira**: Implementação da casa de madeira.
- **CasaDeTijolo**: Implementação da casa de tijolo.
